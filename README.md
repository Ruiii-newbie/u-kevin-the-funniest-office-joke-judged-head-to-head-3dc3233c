One short office joke: a setup and a turn, punchline last. The daily
standup is fifteen minutes, it runs forty-five, and the only agile thing
about the team is how fast the meeting dodges its own agenda.

## Run

```sh
python3 main.py   # writes the joke to /output/entry.txt
```
